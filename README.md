# Student Performance Predictor & Analytics Dashboard

An end-to-end Machine Learning project that predicts student academic performance using behavioral and academic factors, integrated with a Flask web application and Power BI dashboard for analytics and visualization.

## Features

- Student Performance Prediction
- Interactive Analytics Dashboard
- Machine Learning Model Comparison
- Data Visualization & EDA
- Flask Web Application
- MySQL Database Integration
- Batch Prediction using CSV
- Automated Model Retraining
  

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- MySQL
- Power BI
- Matplotlib
- Seaborn
- Joblib

## Machine Learning Workflow

Raw Data → Data Cleaning → Feature Engineering → Model Training → Evaluation → Flask App → Dashboard

## Objective

The goal of this project is to identify students who are at risk of poor academic performance at an early stage so educators can provide timely support and intervention.
